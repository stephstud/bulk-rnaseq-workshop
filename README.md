# Bulk RNA-seq Workshop

Materials for *Introduction to Bulk RNA-seq Analysis*, a practical workshop at Monash University Malaysia covering RNA-seq analysis in R from raw counts through quality control, normalisation, differential expression, and pathway enrichment.

**Workshop site:** https://stephstud.github.io/bulk-rnaseq-workshop/

## Contents
*Materials will be added closer to the workshop start date.*
- `1-lectures/` — lecture slides
- `2-practicals/` — R Markdown practicals (QC & filtering, differential expression, pathway enrichment)
